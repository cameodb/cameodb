## Phase 1: Code Review Issues & Critical Fixes

**Priority**: HIGH - Address critical bugs and resource leaks identified in code review

### **Step 1.1: Resource Leak - Read Runtime Shutdown**
**Severity**: ✅ RESOLVED
**Issue**: Dedicated read runtime (`Arc<tokio::runtime::Runtime>`) created but never properly shut down

**Location**: `crates/server/src/node_orchestrator.rs` lines 5438-5464

**Fix Implemented**:
```rust
impl Drop for NodeOrchestrator {
    fn drop(&mut self) {
        if let Some(read_runtime) = self.read_runtime.take() {
            match Arc::try_unwrap(read_runtime) {
                Ok(runtime) => runtime.shutdown_background(),
                Err(arc) => {
                    // Other references exist (shards still hold handles)
                    // Runtime will be cleaned up when last Arc is dropped
                }
            }
        }
    }
}
```

### **Step 1.2: Writer Thread Starvation Prevention**
**Severity**: ✅ RESOLVED
**Issue**: `try_recv()` loop could run indefinitely, delaying actual processing

**Location**: `crates/server/src/node_orchestrator.rs` lines 1157-1165

**Fix Implemented**:
```rust
// Limit drain to prevent starvation - max 64 additional commands per iteration
const MAX_DRAIN_PER_ITERATION: usize = 64;
pending_cmds.clear();
pending_cmds.push(first_cmd);
let mut drained = 0;
while drained < MAX_DRAIN_PER_ITERATION {
    match rx.try_recv() {
        Ok(cmd) => {
            pending_cmds.push(cmd);
            drained += 1;
        }
        Err(_) => break, // Channel empty or disconnected
    }
}
```

### **Step 1.3: Batch Coalescing Math Error**
**Severity**: ✅ RESOLVED
**Issue**: Rounding errors in `new_docs` distribution may not sum to original total

**Location**: `crates/server/src/node_orchestrator.rs` lines 1299-1317

**Fix Implemented**:
```rust
// Use integer arithmetic with remainder distribution to avoid rounding errors
let total_segments = reply_segments.len();
for (idx, (op_count, reply)) in reply_segments.into_iter().enumerate() {
    let segment_new_docs = if idx == total_segments - 1 {
        // Last segment gets all remaining to ensure exact total
        remaining_new_docs
    } else if total_ops > 0 {
        // Integer division with proper distribution
        let proportional = (new_docs * op_count) / total_ops;
        proportional.min(remaining_new_docs)
    } else {
        0
    };
    remaining_new_docs = remaining_new_docs.saturating_sub(segment_new_docs);
    let _ = reply.send(Ok((segment, segment_new_docs)));
}
```
