# CameoDB Optimization & Architecture Upgrade Plan

This document outlines the refactoring strategy to transform CameoDB into a high-throughput, crash-consistent distributed database.

## Phase 1: Storage Durability (WAL Recovery)
**Goal:** Guarantee data consistency after a crash by implementing Version Vectoring in the WAL.

### Step 1.1: Add Sequence ID to Schema
**Context:** To detect stale data during recovery, every document in Tantivy must carry the WAL sequence ID that created it.

**Instruction for Windsurf Agent:**
> In `storage/src/lib.rs`, modify `HybridStore::create_schema_from_definition`.
> 1.  Add a reserved field `_seq` to the Tantivy schema (`u64`, `STORED`, `FAST`).
> 2.  Update `apply_write` and `apply_batch` to inject the `seq_id` into the `tantivy_doc` when creating it.

```rust
// storage/src/lib.rs

// 1. Modify create_schema_from_definition
fn create_schema_from_definition(...) {
    // ...
    let seq_field = schema_builder.add_u64_field("_seq", STORED | FAST);
    // ...
}

// 2. Update apply_batch / apply_write
// Inside the loop creating tantivy_doc:
let mut tantivy_doc = doc!(
    fields.id => id.as_str(),
    fields.seq => seq_id // Inject the WAL sequence
);

```

### Step 1.2: Implement WAL Replay

**Context:** On startup, scan the WAL backwards to find the "Sync Point" where `index_seq == wal_seq`.

**Instruction for Windsurf Agent:**

> In `storage/src/lib.rs`, implement `HybridStore::recover_from_wal(index: &str)`.
> 1. Open `wal_{index}`.
> 2. Iterate backwards (`rev()`).
> 3. Check `_seq` in Tantivy vs WAL.
> * If `stored_seq >= wal_seq`: **Synced**. Stop.
> * If `stored_seq < wal_seq` or missing: **Replay** op to writer.
> 
> 
> 4. Call this inside `HybridStore::new()`.
> 
> 

### Step 1.3: Clean Code - Shorten Critical Section

**Context:** Keep database write transactions as short as possible by performing serialization before acquiring the global write lock. This is a stability best practice.

**Instruction for Windsurf Agent:**

> In `storage/src/lib.rs`, refactor `apply_batch`.
> 1. Create a `prepared_ops` vector.
> 2. Iterate ops, serialize `WalOp` and `StoredDoc` to `Vec<u8>`, and push to `prepared_ops` (No lock held).
> 3. Only then call `self.kv.begin_write()` and loop through `prepared_ops` to insert raw bytes (Lock held).

```rust
// storage/src/lib.rs

struct PreparedOp {
    wal_bytes: Vec<u8>,
    doc_bytes: Option<Vec<u8>>,
    id: String,
}

impl HybridStore {
    pub fn apply_batch(&self, index: &str, ops: Vec<WalOp>) -> Result<(Vec<u64>, usize), StoreError> {
        // Step 1: Serialize outside of lock (CPU work)
        let mut prepared_ops = Vec::with_capacity(ops.len());
        for op in ops {
            match op {
                WalOp::Put { id, json_blob } => {
                    let wal_bytes = serde_json::to_vec(&op)?;
                    let doc_bytes = json_blob.map(|blob| 
                        serde_json::to_vec(&StoredDoc { json_blob: Some(&blob) })?
                    );
                    prepared_ops.push(PreparedOp { wal_bytes, doc_bytes, id });
                }
                WalOp::Delete { id } => {
                    prepared_ops.push(PreparedOp { 
                        wal_bytes: serde_json::to_vec(&op)?, 
                        doc_bytes: None, 
                        id 
                    });
                }
            }
        }
        
        // Step 2: Minimal critical section (IO work only)
        let mut write_txn = self.kv.begin_write()?;
        let mut new_docs = 0;
        
        {
            let mut wal_table = write_txn.open_table(wal_table_def)?;
            let mut data_table = write_txn.open_table(data_table_def)?;
            
            for (seq_id, prepared) in prepared_ops.into_iter().zip(start_seq..) {
                wal_table.insert(seq_id, prepared.wal_bytes.as_slice())?;
                
                if let Some(doc_bytes) = prepared.doc_bytes {
                    if data_table.insert(&prepared.id, doc_bytes.as_slice())?.is_none() {
                        new_docs += 1;
                    }
                } else {
                    data_table.remove(&prepared.id)?;
                }
            }
        }
        
        write_txn.commit()?;
        Ok((seq_ids, new_docs))
    }
}
```

## Phase 2: Microshard Throughput (The "Writer Thread" Pattern)

**Goal:** Move writes to a dedicated, lock-free thread per shard, while keeping reads parallel in the thread pool.

### Step 2.1: Define Storage Commands

**Instruction for Windsurf Agent:**

> In `node_orchestrator/src/microshard.rs`, define the `StorageCommand` enum.

```rust
// node_orchestrator/src/microshard.rs

pub enum StorageCommand {
    Write {
        req: WriteRequest,
        reply: tokio::sync::oneshot::Sender<Result<u64, OrchestratorError>>,
    },
    BatchWrite {
        req: BatchWriteRequest,
        reply: tokio::sync::oneshot::Sender<Result<Vec<u64>, OrchestratorError>>,
    },
    // Note: Search is NOT here. Searches are read-only and parallel.
    Shutdown(tokio::sync::oneshot::Sender<()>),
}

```

### Step 2.2: Refactor MicroshardActor

**Instruction for Windsurf Agent:**

> Refactor `MicroshardActor`.
> 1. **Split ownership:** Keep `Arc<HybridStore>` for Reads. Add `flume::Sender<StorageCommand>` for Writes.
> 2. **Start Writer Thread:** In `start()`, spawn a `std::thread` that takes a clone of the store and processes the Write channel.
> 3. **Handle Writes:** Send to channel.
> 4. **Handle Reads:** Keep using `tokio::task::spawn_blocking` (so multiple searches on the same shard can run in parallel).
> 
> 

```rust
// node_orchestrator/src/microshard.rs

pub struct MicroshardActor {
    shard_id: Uuid,
    store: Arc<HybridStore>, // For Reads (Parallel)
    writer_tx: flume::Sender<StorageCommand>, // For Writes (Serialized)
    config: StorageConfig,
    // ...
}

impl MicroshardActor {
    pub async fn start(&mut self) -> Result<(), OrchestratorError> {
        // Initialize Store (Blocking I/O)
        let store = Arc::new(tokio::task::spawn_blocking({
            let cfg = self.config.clone();
            move || HybridStore::new(cfg)
        }).await??);
        
        self.store = store.clone();
        
        // Writer Channel
        let (tx, rx) = flume::unbounded();
        self.writer_tx = tx;
        let writer_store = store.clone();
        let shard_id = self.shard_id;

        // SPAWN DEDICATED WRITER THREAD (1 per Shard)
        std::thread::Builder::new()
            .name(format!("writer-shard-{}", shard_id))
            .spawn(move || {
                while let Ok(cmd) = rx.recv() {
                    match cmd {
                        StorageCommand::Write { req, reply } => {
                            // Pre-serialize here if possible (Phase 1.2 optimization)
                            let op = WalOp::Put { id: req.id, json_blob: Some(req.doc) };
                            let res = writer_store.apply_write(&req.index, op)
                                .map_err(OrchestratorError::from);
                            let _ = reply.send(res);
                        }
                        StorageCommand::BatchWrite { req, reply } => {
                            // ... handle batch ...
                        }
                        StorageCommand::Shutdown(reply) => {
                            let _ = writer_store.shutdown();
                            let _ = reply.send(());
                            break;
                        }
                    }
                }
            })?;
        Ok(())
    }

    // READER PATH: Parallel (Thread Pool)
    pub async fn handle_search(&self, req: SearchRequest) -> Result<SearchReply, OrchestratorError> {
        let store = self.store.clone();
        tokio::task::spawn_blocking(move || {
            store.search_documents(...)
        }).await?
        .map_err(OrchestratorError::from)
    }

    // WRITER PATH: Serialized (Dedicated Thread)
    pub async fn handle_write(&self, req: WriteRequest) -> Result<u64, OrchestratorError> {
        let (reply_tx, reply_rx) = tokio::sync::oneshot::channel();
        self.writer_tx.send_async(StorageCommand::Write { req, reply: reply_tx }).await
            .map_err(|_| OrchestratorError::Io(std::io::Error::other("Writer closed")))?;
        reply_rx.await
            .map_err(|_| OrchestratorError::Io(std::io::Error::other("Writer dropped response")))?
    }
}

```

### Step 2.3: Parallel Serialization (The "IO Pump" Pattern)

**Context:** Maximize throughput by parallelizing the CPU-heavy JSON serialization across all Shard Actors (running on Tokio threads) before handing off raw bytes to the single-threaded Writer.

**Instruction for Windsurf Agent:**

> **Storage Crate:** Expose `HybridStore::prepare_batch_ops(ops: Vec<WalOp>) -> Vec<PrePackedOp>` and `apply_pre_packed(...)`.
> 
> **Microshard Actor:** In `handle_batch_write`:
> 1. Use `tokio::task::spawn_blocking` to call `prepare_batch_ops` (Parallel CPU work).
> 2. Send `StorageCommand::PrePackedBatchWrite` to the dedicated thread (Fast IO work).

```rust
// storage/src/lib.rs

#[derive(Debug)]
pub struct PrePackedOp {
    pub wal_data: Vec<u8>,      // Serialized WalOp
    pub doc_data: Option<Vec<u8>>, // Serialized StoredDoc
    pub op_type: OpType,        // Put or Delete
    pub id: String,             // Document ID
}

impl HybridStore {
    /// Serialize all operations outside of any database locks
    pub fn prepare_batch_ops(&self, ops: Vec<WalOp>) -> Result<Vec<PrePackedOp>, StoreError> {
        let mut prepared = Vec::with_capacity(ops.len());
        
        for op in ops {
            match op {
                WalOp::Put { id, json_blob } => {
                    // Serialize WalOp for WAL
                    let wal_data = serde_json::to_vec(&op)?;
                    // Serialize StoredDoc for data table
                    let doc_data = json_blob.map(|blob| {
                        serde_json::to_vec(&StoredDoc { json_blob: Some(&blob) })?
                    });
                    
                    prepared.push(PrePackedOp {
                        wal_data, doc_data, 
                        op_type: OpType::Put, id,
                    });
                }
                WalOp::Delete { id } => {
                    prepared.push(PrePackedOp {
                        wal_data: serde_json::to_vec(&op)?,
                        doc_data: None,
                        op_type: OpType::Delete,
                        id,
                    });
                }
            }
        }
        Ok(prepared)
    }
    
    /// Apply pre-serialized operations with minimal lock time
    pub fn apply_pre_packed(&self, index: &str, prepared_ops: Vec<PrePackedOp>) -> Result<(Vec<u64>, usize), StoreError> {
        // Generate sequence IDs
        let start_seq = self.current_seq.get(index)
            .ok_or_else(|| StoreError::IndexNotFound(format!("Index: {}", index)))?
            .fetch_add(prepared_ops.len() as u64, Ordering::SeqCst) + 1 - prepared_ops.len() as u64;
        
        // Minimal critical section - only database writes
        let mut write_txn = self.kv.begin_write()?;
        let mut new_documents_count = 0;
        
        {
            let mut wal_table = write_txn.open_table(wal_table_def)?;
            let mut data_table = write_txn.open_table(data_table_def)?;
            
            // Fast path: just insert pre-serialized bytes
            for (prepared_op, seq_id) in prepared_ops.into_iter().zip(start_seq..) {
                wal_table.insert(seq_id, prepared_op.wal_data.as_slice())?;
                
                match prepared_op.op_type {
                    OpType::Put => {
                        if let Some(doc_data) = prepared_op.doc_data {
                            if data_table.insert(&prepared_op.id, doc_data.as_slice())?.is_none() {
                                new_documents_count += 1;
                            }
                        }
                    }
                    OpType::Delete => {
                        data_table.remove(&prepared_op.id)?;
                    }
                }
            }
        }
        
        write_txn.commit()?;
        Ok(((start_seq..start_seq + prepared_ops.len() as u64).collect(), new_documents_count))
    }
}

// node_orchestrator/src/microshard.rs

pub enum StorageCommand {
    // ... existing variants
    PrePackedBatchWrite {
        ops: Vec<PrePackedOp>,
        reply: tokio::sync::oneshot::Sender<Result<(Vec<u64>, usize), OrchestratorError>>,
    },
}

impl MicroshardActor {
    pub async fn handle_batch_write(&self, req: BatchWriteRequest) -> Result<Vec<u64>, OrchestratorError> {
        let store = self.store.clone();
        
        // Step 1: Parallel CPU work - serialize all operations
        let prepared_ops = tokio::task::spawn_blocking(move || {
            store.prepare_batch_ops(req.ops)
        }).await??;
        
        // Step 2: Fast IO work - send to dedicated writer thread
        let (reply_tx, reply_rx) = tokio::sync::oneshot::channel();
        self.writer_tx.send_async(StorageCommand::PrePackedBatchWrite {
            ops: prepared_ops,
            reply: reply_tx,
        }).await?;
        
        let (seq_ids, _new_docs) = reply_rx.await??;
        Ok(seq_ids)
    }
}
```

## Phase 3: Router Latency (The Fast Path)

**Goal:** Bypass the `NodeOrchestrator` bottleneck for high-volume data operations.

### Step 3.1: Add Shard Cache & Logic

**Instruction for Windsurf Agent:**

> In `node_orchestrator/src/router_actor.rs`:
> 1. Add `local_shards: Arc<DashMap<Uuid, ActorRef<MicroshardActor>>>`.
> 2. In `route_and_handle`, check this cache **first** after getting the Shard ID from the coordinator.
> 3. If found, call `shard.ask()` directly. If not, fallback to `self.orchestrator.ask()`.
> 
> 

```rust
// node_orchestrator/src/router_actor.rs

async fn route_local(&self, op: ClientOp, shard_id: Uuid) -> Result<JsonValue, OrchestratorError> {
    // 1. FAST PATH
    if let Some(shard) = self.local_shards.get(&shard_id) {
        return self.forward_to_shard(shard.value(), op).await;
    }

    // 2. CACHE MISS & RETRY
    self.refresh_shard_map().await;
    if let Some(shard) = self.local_shards.get(&shard_id) {
        return self.forward_to_shard(shard.value(), op).await;
    }

    // 3. FALLBACK (Slow Path)
    self.orchestrator.ask(op).await
}

```
